# 🚗 智慧交通異常偵測系統(開發中)

`Unity` `YOLO` `交通安全` `異常偵測` `電腦視覺` 

## 📌 專案介紹
結合 Unity 模擬環境與 YOLO 物件偵測技術，建立可即時辨識車輛異常行為的智慧交通系統。  
系統能分析車輛速度與行駛位置，偵測龜速車、壓線等異常行為，並提供可視化結果。

---

## 🎯 專案動機
在現實交通中，異常駕駛行為可能導致壅塞或事故。  
本專案透過模擬與影像辨識技術，建立一套可即時分析車輛行為的系統，以提升交通監控與分析能力。

---

## 🛠️ 技術架構
- Unity（車流模擬與場景建構）  
- YOLO（車輛物件偵測）  
- C#（車輛行為控制與邏輯設計）  
- Python / OpenCV（影像處理與模型整合）  

---

## ⚙️ 系統流程
1. 車輛在 Unity 模擬環境中生成並行駛  
2. 擷取畫面並輸入 YOLO 進行車輛偵測  
3. 分析車輛位置與速度資訊  
4. 判斷異常行為（龜速 / 壓線）  
5. 將結果回饋至系統並進行可視化呈現  

---

## 🔍 核心功能
- **車輛偵測**：YOLO 即時辨識多車輛  
- **龜速車偵測**：透過速度閾值判斷低速異常  
- **壓線偵測**：判斷車輛是否偏離車道  
- **換道與跟車邏輯**：設計安全距離與換道判斷，避免碰撞  
- **異常事件統計**：統計異常事件發生次數，便於分析  

---

## 🧠 技術亮點
- 結合模擬環境與影像辨識的系統整合能力  
- 車輛行為分析模型設計（速度、位置、車道）  
- 多條件判斷邏輯提升偵測準確度  
- 模擬多種交通場景（壅塞、異常行為）

# 🧵 布料瑕疵偵測系統
`Python` `OpenCV` `背景建模` `影像差分`

---

## 📌 專案介紹
本專案建立一套基於影像處理的布料瑕疵偵測系統，透過背景建模與影像差分技術，自動辨識布料中的缺陷區域，並評估偵測效能。

---

## 🎯 專案動機
在工業生產中，布料瑕疵檢測多仰賴人工，效率低且易受主觀影響。本專案透過電腦視覺技術，實現自動化瑕疵檢測流程，以提升檢測效率與準確性。

---

## 🛠️ 技術架構
- Python  
- OpenCV  
- NumPy  

---

## ⚙️ 系統流程
1. 讀取影片並建立背景模型（Median Background）  
2. 進行影像差分取得異常區域  
3. 二值化與形態學運算去除雜訊  
4. 使用連通元件分析找出缺陷區域  
5. 區域成長（Region Growing）擴展缺陷範圍  
6. 輸出結果並進行效能評估  

---

## 🔍 核心功能
- 背景建模：建立穩定背景以提升偵測準確度  
- 瑕疵偵測：透過影像差分與閾值處理找出缺陷  
- 雜訊過濾：使用形態學運算去除非目標區域  
- 區域分析：透過連通元件定位主要缺陷  
- 效能評估：計算 Accuracy、Precision、Recall  

---

## 🧠 技術亮點
- 建立完整影像處理 pipeline（非黑盒AI）  
- 結合多種影像處理技術提升穩定性  
- 設計區域成長機制優化缺陷偵測範圍  
- 建立自動化評估流程驗證模型效能

# 🌏 地震資料分析與資料庫系統

`Database` `SQL` `Data Analysis` `Web Development`

---

## 📌 專案介紹
本專案建立一套地震資料分析與查詢系統，透過整理政府公開資料並建置資料庫，提供地震資訊的查詢、統計與視覺化呈現。

---

## 🎯 專案動機
地震資料雖為公開資訊，但多以分散形式存在，不利於查詢與分析。本專案透過資料庫設計與網頁系統整合，提升資料使用效率與分析便利性。

---

## 🛠️ 技術架構
- Python  
- SQL  
- Web（HTML / JavaScript）  

---

## ⚙️ 系統流程
1. 蒐集地震資料（人工建立資料集）   
2. 建立資料庫與資料表  
3. 實作查詢與統計功能  
4. 透過網頁介面呈現資料  

---

## 🔍 核心功能
- 地震資料管理：儲存時間、地點、規模、深度等資訊  
- 資料查詢：支援條件篩選與資料檢索  
- 統計分析：分析特定區間或地區地震次數  
- 視覺化呈現：透過網頁顯示資料結果  

---

## 🧠 技術亮點
- 建立完整資料處理流程（蒐集 → 清洗 → 儲存 → 查詢）  
- 設計資料庫結構提升查詢效率  
- 整合後端資料與前端呈現
